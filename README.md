## 1. PopOut Player

Floating mini-player that lets users watch videos while working on other tabs or applications.

### Features
- Always-on-top video window  
- Supports all HTML5 video platforms  
- Draggable and resizable player  
- Lightweight and privacy-friendly  



---

## 2. Sound On Extension

Adds fun sound effects on each page load.

### Features
- Randomized sound effects  
- Instant trigger after page load  
- Simple and lightweight
